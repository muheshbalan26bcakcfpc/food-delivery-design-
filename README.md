# food-delivery-design-
FoodExpress – Food Delivery App
A mobile food delivery application UI/UX design (iOS) covering the complete user journey from browsing restaurants to placing an order and making payment.

App Screens
Home Screen

Search bar to find restaurants, cuisines, or dishes
Category browsing (Pizza, Burger, Desserts, Beverages, etc.)
Featured items — Cheesy Pizza, Chicken Burger, Paneer Pizza, etc.
Quick "Deals for you" and offers section
Category / Listing Screens

Item cards with image, name, rating, delivery time
Price with discount badges (e.g., 50% OFF up to ₹XX)
"Deals for you" carousel per category (Pizza, Burger, Desserts, Ice Cream)
Item Detail Screen

Large product image
Item name, price, description
"Order" call-to-action button
Delivery ETA and outlet info
Cart / Order Summary Screen

Restaurant name and item list
Cart total, delivery fee, discount applied
GST & other charges breakdown
"To Pay" total amount
Checkout / Payment Screen

Delivery address & instructions
Suggestion notes (e.g., leave at door, call before delivery)
Bill details: Item Total, Delivery Fee, Discount, Taxes
Sticky PAY button at the bottom
Key Features
Search & browse restaurants/dishes by category
Real-time discounts and combo deals
Cart with editable quantities and live bill calculation
Transparent bill breakup before payment
Order tracking-ready flow (Home → Item → Cart → Pay)
Clean, minimal red-and-white themed UI, optimized for iPhone
Design
Platform: iOS (iPhone mockups)
Theme: Red & white with card-based layout
Style: Rounded cards, bottom navigation bar (Home, Search, Cart, Profile)
